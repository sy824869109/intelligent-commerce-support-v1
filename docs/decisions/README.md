# 架构决策记录

ADR 用于记录影响多个模块、长期维护、数据边界、安全或部署方式的重要决定。

## 编号和文件名

- 模板：`ADR-0000-template.md`
- 正式记录：`ADR-NNNN-short-kebab-title.md`
- 编号只增不减，已使用编号不得复用。

## 状态

- `Proposed`：待评审。
- `Accepted`：已经采用。
- `Deprecated`：仍保留历史，但不建议新使用。
- `Superseded by ADR-NNNN`：被新决策取代。
- `Rejected`：评审后未采用。

已经接受的 ADR 不直接改写结论。需要改变决定时新增 ADR，并在旧记录中仅补充“被哪个 ADR 取代”的状态链接。
