# ADR-0009：身份、租户与资源授权

- 状态：Accepted
- 日期：2026-09-10
- 范围：M03.1–M03.4；用户授权完成全部 M03

## 背景

M02 已提供网关、事务、审计及业务合同，但没有可验证身份。开始资源查询前必须冻结租户权限来源与会话失效方式，且不能修改原 KF。

## 决策驱动因素

即时吊销、跨租户拒绝、状态可审计、双平台可验证、现有依赖可复用，以及不把身份校验交给模型。

## 决策

1. 用户账号全局唯一，使用小写用户名；组织下包含租户，账号通过租户成员关系获得 CUSTOMER / AGENT / ADMIN 角色。管理员权限不跨租户，客服组也是租户内实体。
2. 使用服务端会话及不透明 Bearer 令牌。访问令牌有效期最多 5 分钟，会话与刷新令牌绝对期限 7 天；刷新后旧访问令牌失效。数据库只保存随机令牌的 SHA-256 摘要，不使用自包含 JWT 权限声明。
3. 刷新在会话行锁内轮换。已用刷新令牌重放会提交整个会话的吊销，再返回认证失败；并发刷新只能有一个成功结果，重放会使其后继也失效。客户端须串行刷新，不能对未知刷新结果盲目并发重试。
4. 请求每次按当前数据库状态验证用户、租户、成员、会话和角色权限。资源事实由领域数据库查询提供；不接受客户端自报 owner、tenant、role 作为权限证据。
5. 明确选择 Header Bearer 模式，不签发认证 Cookie。浏览器令牌只保存在内存；跨源请求需明确 Origin 白名单，不启用宽松 CORS，不允许 URL 令牌。未来 SSE 使用支持 Header 的 fetch 流客户端；不为原生 EventSource 把令牌放 URL。
6. 密码使用当前 Python 标准库 scrypt：N=131072、r=8、p=1、独立 16 字节随机盐、32 字节输出。至少 15 字符，最多 128 字符/512 UTF-8 字节；拒绝小型常见弱密码集及极低字符多样性，不截断或自动修剪密码。不是完整泄露密码库检查，也不宣称 NIST 合规认证。
7. 固定角色/权限由迁移初始化，不创建默认管理员或密码。首个管理员由本机操作员交互式设置；后续成员由租户管理员创建。禁用/降权最后一个可用管理员被拒绝。
8. 身份变更、成功登录/刷新、吊销及密码修改与审计使用同一事务。诊断日志不记录密码、令牌或原始查询；未认证尝试通过持久化限流记录控制，不伪造已认证 actor 写审计。

## 理由与参考

现有环境未包含 Argon2，选择已有标准库的 scrypt，避免本阶段引入新运行依赖；成本参数采用 OWASP 列出的 scrypt 档位。[OWASP Password Storage](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)

服务端状态便于立即吊销和重查权限；令牌只负责定位会话，不携带不可撤销的权限副本。有关会话令牌及生命周期的参考：[OWASP Session Management](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)。本方案为本项目的具体实现选择，不声称参考材料逐项要求了上述时间值。

## 约束与后果

- 暂保持回环开发部署；局域网/生产须完成 HTTPS、代理信任、前端存储及运维限制，M03 不自动开放防火墙或监听所有网卡。
- 数据库不可用时认证/授权失败关闭；不会降级为信任 Header。
- 最多两个并发 scrypt 操作/Identity 实例；IP 20 次/5 分钟、账号与租户组合 5 次/5 分钟；同会话刷新最多 30 次/5 分钟。限流计数存数据库；这些是初始工程边界，可后续经测量调整。
- MFA、联邦登录、找回密码/邀请流程、泄露密码完整库以及企业合规归档不包含在本次四个 M03 子任务中，不宣传为已实现。
- RBAC 允许访问不等于允许立即执行业务：订单状态、工单接管、知识审批、用户确认等额外守卫仍由对应领域负责。

## 备选方案

- 自包含 JWT：便于无状态验证，但动态权限与即时吊销仍要附加服务端状态；本阶段不采用。
- HttpOnly Cookie：适合浏览器会话，但需要额外 Cookie/CSRF 生命周期；本阶段统一选受控 Header。并非认为 Cookie 方案不安全。
- Argon2id：OWASP 优先选择；当前环境无该依赖，选用列出的 scrypt 档位。未来升级需迁移旧哈希并复测资源成本，不静默降级参数。

## 结果与影响

身份依赖数据库可用性；每次授权增加查询成本，换取当前权限与吊销状态。令牌不能离线验权；前端要实现内存保存、串行刷新及过期重新登录。

## 安全与数据影响

新增身份表及固定角色权限种子，不生成真实账号；密码随机盐哈希、令牌摘要存储。无权资源统一 404。审计与身份变更共用事务，过期清理不删除审计。登录限流计数可在多个进程间共享。

## 运维与回滚

显式迁移到 m03_0003 后再启用身份模式；保留回环绑定。操作员交互初始化首个管理员并串行执行。存在任何身份或平台历史时迁移拒绝降级，故回退应用应保留数据库；不能为回退而清空账户、会话或审计。

## 验证方式

双平台后端测试、独立 OpenAPI 漂移检查、三角色资源矩阵、真实 MySQL 外键/并发刷新/吊销、密码策略、Origin/请求限制、审计失败回滚及依赖安全检查。完成情况记录在 M03 验收文档和任务台账。
