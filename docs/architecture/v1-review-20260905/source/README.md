## 修改与生成

在本目录执行以下步骤，输出位于上一级审查材料目录：

1. 使用 Python 3.12 或更高版本运行 `python build_project_flow.py`，生成 SVG 和离线 HTML。不需要第三方 Python 库。
2. 使用装有 Playwright 的 Node 环境和本机 Chrome，运行 `node render_project_flow.cjs <Playwright 模块路径> <仓库外的 QA 目录>`。
3. 查看 QA 目录中的分区 PNG 与网页截图，确认文字、连线、中文显示和资源对应关系，再交付上一级目录的文件。

渲染脚本使用独立无头浏览器，不复用个人 Chrome 配置。它检查 50 个框内文字的边界、流程线穿框、六个区域定位入口以及缩放按钮。PNG 为 2000 × 5260 像素，SVG 为同等坐标系的矢量源图；HTML 无 CDN 或外部网络依赖。脚本只覆盖自己生成的三个补充图文件。原四张图与 Word 为历史快照，当前衔接规则以本图和标准 1.1 为准。
