责任节点唯一负责的事实不应混淆
N1 / N2统一入口 / 身份、租户、角色与安全约束入口授权不代替 N5 业务归属与资格校验
N3正式会话、控制模式、消息、评价、通知不从 KF 诊断历史恢复正式消息
N4Run、确定性路由、Workflow、确认与命令意图不拥有订单事实，不替模型放开业务写权限
N5订单 / 包裹 / 商品 / 售后 / 发票事实、批准规则、预检与命令资格成立、申请受理、审批通过、退款到账是不同事实
N6知识原文与元数据、索引版本、KF 检索与生成保留核心；隔离诊断历史；不能审批订单或执行资金
N7 / N8 / N9工单与人工记录 / 任务执行与投递 / 可观测性N8 通过所属领域端口做事；N9 日志不能代替领域事务审计

MySQL 是各领域的权威数据；MinIO 存原文 / 附件；Milvus 存可重建索引；Redis / Streams 存缓存和投递状态，不能是唯一事实。逻辑边界不要求 V1 将所有模块拆成独立进程。
