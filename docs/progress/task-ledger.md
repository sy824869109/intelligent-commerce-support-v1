## 状态定义

- `TODO`：尚未开始。
- `IN_PROGRESS`：正在实施或尚未通过全部交付门禁。
- `BLOCKED`：存在无法在当前权限或环境内解决的阻塞。
- `DONE`：实现、测试、文档、提交和 GitHub 推送全部完成。
