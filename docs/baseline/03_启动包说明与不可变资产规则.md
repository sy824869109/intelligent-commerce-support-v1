# 启动包说明与不可变资产规则

## 包含内容

```text
智能电商客服重构启动包_当前稳定技术栈/
├─ 00_智能电商客服平台_渐进式重构总控提示词.md
├─ 01_智能电商客服平台_V1重构理解与初步架构.md
├─ 02_当前技术选型基线.md
├─ 03_启动包说明与不可变资产规则.md
├─ SHA256SUMS.txt
└─ references/
   ├─ intelligentAssistant.zip
   ├─ intelligentAssistant_backup_60passed.zip
   └─ knowforge-rag-platform.zip
```

## 使用边界

1. `references/` 中三个压缩包仅用于只读分析，不是新项目目录。
2. 新项目必须在独立目录、独立 Git 仓库中从零搭建。
3. 开始前运行 SHA-256 校验；校验值必须与 `SHA256SUMS.txt` 一致。
4. 参考包不进入新项目 GitHub；把文件名、目录和常见压缩格式写入 `.gitignore`。
5. 不要从参考包复制密钥、`.env`、运行数据、日志、模型权重或构建产物。依赖版本需按新平台兼容矩阵重新锁定，不能直接复制参考锁文件。
6. 可从原电商项目提炼需求、测试样例和业务规则；可在新项目复刻 KF RAG 核心架构，但不得就地修改参考源。

## 校验命令（PowerShell）

```powershell
Get-FileHash -Algorithm SHA256 .\references\intelligentAssistant.zip
Get-FileHash -Algorithm SHA256 .\references\intelligentAssistant_backup_60passed.zip
Get-FileHash -Algorithm SHA256 .\references\knowforge-rag-platform.zip
```

## 归档格式

完整交付采用未二次压缩的 `.tar`：内部三个源文件已经是 ZIP，继续二次压缩收益很小；TAR 也规避部分 ZIP 工具对 4GB 以上单文件或归档的兼容限制。
