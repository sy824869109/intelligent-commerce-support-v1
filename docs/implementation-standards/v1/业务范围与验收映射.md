# V1 业务范围与验收映射

版本 1.1 · 2026-09-06。依据 B-12，覆盖总控计划十四类场景，不代表每项均自动办理或已上线。

表中“读/申请”是建设目标：DEMO 环境使用合成事实；真实渠道只有授权、合同及运行测试通过才登记 LIVE。未接通真实渠道时明确 HUMAN_ONLY 受理，不从 LIVE 静默切换演示。知识说明必须已有批准依据，无依据则澄清/人工。N7 受理不等于人工已完成外部业务。

模块实施时将每个子场景细化成带输入、预期路由、状态、数据变化、用户文案、审计及恢复的子用例。起始编号可关联多个参数化子例，但报告需逐例保留结果。这里未宣称 93 条用例足以穷尽市场情况。

发布前逐项检查：模式登记不是空值；LIVE 有渠道证据；DEMO 显著标识；HUMAN_ONLY 有真实可查询的受理记录和责任人；UNSUPPORTED 有明确说明和安全替代入口。范围变更必须同步总控任务覆盖说明、合同、UI 和测试，不擅自删除原有需求。
