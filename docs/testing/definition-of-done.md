# Definition of Done

## 单张任务卡完成条件

一张任务卡只有同时满足以下条件才能标记 `DONE`：

- 范围与任务台账一致，没有混入无关重构；
- 正常路径、错误路径、权限和边界条件已经实现；
- 相关单元、集成、契约或界面测试真实通过；
- 静态检查、格式检查和结构检查通过；
- 数据库迁移、配置样例、接口合同和回滚方式齐全；
- 公共接口和复杂业务规则有最新注释，旧注释已同步；
- 不包含密钥、隐私数据、模型、大型归档或构建产物；
- 已审查 `git diff`，创建原子提交并成功推送 GitHub；
- 任务台账记录提交、验证证据、风险和下一任务。

只完成代码但没有测试、文档或远端提交时，状态仍是 `IN_PROGRESS`。

## 模块完成条件

- 模块 README 的职责、接口、表、事件、错误码和运行方式与实现一致；
- 数据所有权和跨服务调用符合 ADR-0001；
- 有可重复的本地启动和测试命令；
- 超时、重试、幂等、审计、脱敏和降级策略覆盖适用路径；
- 依赖故障不会产生无提示失败、脏写或不可恢复状态；
- 阶段 PR 已审查并通过 CI。

## V1 发布完成条件

- P0/P1 业务场景通过，三类前端可在局域网访问；
- 用户问题能按策略进入业务查询、KF RAG、澄清或人工工单；
- 每轮结果可追踪并形成反馈、纠错、质检和评测闭环；
- RAG 有引用、拒答、租户隔离和提示注入防护；
- 备份、恢复、索引重建和版本回滚完成真实演练；
- 发布物包含版本、变更日志、部署包、SBOM 和校验值。
